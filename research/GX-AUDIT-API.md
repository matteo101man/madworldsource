# Native GX audit

native-gx-audit.graph.jsonl indexes the first64 original recompiled bootstrap draw submissions (256vertices), each with finite decoded positions. It retains original TEV BP words and XF material/ambient/light position bits. Projection raw float bits remain in the source evidence/native-gx-draw-audit.jsonl. This is boot UI, not RinRin arena and not pixel verification. The optional source packet bridge flattens display lists once, uses shared native MEM1/MEM2, and invalidates tracked texture content generations at every original draw because native stores bypass Rust tracking. Current sink records state and discards rendering actions.

Vocabulary: native-gx-draw uses-program-state native-tev-inputs; native-gx-draw uses-light-state native-xf-light-inputs. Query with python -m gk graph (asset-free toolkit). Draw packets and hardware inputs are original CPU output, while decoding is supplied by pinned Gecko. This evidence can replace guessed uniforms only after matching the relevant Rin draw/material and verifying rendered equivalence.

Effect-init-calls graph separately records four static native call sites (execution/order requires runtime). The original world loader802140e4 calls effect table initialization801fc51c; the initializer calls cleanup801fc87c and then allocates/fills the256-byte lookup stored at manager8069550c+54. Native core crashes querying index45 while that pointer is zero; diagnostics now trace initialization/update order without skipping or modifying the original bodies.


Stage selection: optional MW_GX_AUDIT_SCENE=0x201 records only after the original world loader returns for that scene. Optional MW_GX_AUDIT_MIN_TEV and MW_GX_AUDIT_PERSPECTIVE avoid startup/UI draws. Captures retain raw float bits for TEV registers/konst, channel controls and all light color/attenuation/position/direction values, plus finite vertex-attribute checks. The first stage201 capture without material filtering still contains one-stage UI; do not identify that as character shading.
