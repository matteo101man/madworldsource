# Remote speaker index

Reproduce with tools/index_speaker_protocol.py. remote-speaker.graph.jsonl indexes report IDs, register meanings, gated codec state, the PC mono/stereo route and narrowly scoped evidence. REMOTE-SPEAKER-API.md contains bounded protocol/route pseudocode and limits. remote-speaker-reference.json pins the primary upstream sources. native-remote-audio-summary.json separates baseline and updated replay observations.
